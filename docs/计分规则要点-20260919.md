# 决赛计分规则（组委会 09-19 群发《决赛计分规则.docx》，副本 桌面/赵文博/决赛文档/）
1. 按参赛模式设折算系数；须完成全部指定点位；未完成 / 偏离路线 / 违反安全 / 设备异常违规 → 扣减、无效或取消。总成绩 = 完成时间 / 模式系数，越低越优。
2. 到达标准：机器人有部位进入红色圆点周围半径 0.25 m 的圆圈。
3. **手动计算各个模式用时，除以相对系数**（分段计时：哪段用什么模式，那段就除那段的系数）。
4. **摔倒后需操纵其起立，恢复时间计入总时间，按 1 倍计算**（摔倒不判无效）。
5. **三次机会，按最优成绩计算**。
6. 设备故障导致无法完赛：该次无效，并新增一次机会。
