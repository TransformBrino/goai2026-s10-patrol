# S10 内置运控接口速查（据《软件开发指南》V1.0.1，2026-08-31；组委会 09-19 开放内置运控接口）

## 1. 三层开关
| 层 | 取值 | 下发方式 |
|---|---|---|
| 使用模式 ControlUsageMode | 常规 0 / **导航 1** / 辅助 2 | 协议 1.2.2（Type 0x00100002, Cmd 0x00500002, Items.Mode） |
| 运动状态 MotionState | 站立 1 / 关节阻尼(软急停) 2 / 趴下 4 / **RL 控制 17**（空闲 0、开机阻尼 3 只读） | 协议 1.2.3（Cmd 0x00200002, MotionParam）或话题 `/MOTION_STATE`（drdds/MotionState）。**协议站立后自动进 RL；话题站立后要再发 17** |
| 步态 Gait | 基础 0x1001、楼梯 0x1003（常规运动模式）；**平地 0x3002、楼梯 0x3003（导航/敏捷运动模式）** | 协议 1.2.4（Cmd 0x00300002, GaitParam）或话题 `/GAIT`（drdds/Gait，只有 0x3002/0x3003） |

## 2. 二次开发做自主导航的硬规矩（指南原话要点）
- 必须用**导航运动模式的专用步态**（0x3002 / 0x3003）并配合**真实轴指令**控制。
- 楼梯：**进入楼梯前**切 0x3003，**严禁进楼梯后再切**；直线导航爬楼梯时目标点标到最后一阶边缘 45 cm 以外并关闭导航停避障。
- 步态切换指令须在机器人**完全停止**后下发；有速度时下发会被缓存，停止后才执行。
- 速度指令：话题 `/NAV_CMD`（drdds/NavCmd：x_vel、y_vel m/s，yaw_vel rad/s；**仅导航模式生效，建议 10 Hz**）或协议 1.2.6 真实轴指令（Cmd 0x00110002，X ±1.67 m/s、Y ±0.4 m/s、Yaw ±1.0 rad/s，不做额外限速，仅导航模式生效，不回响应）。
- 常规模式的轴指令（1.2.5）是归一化 [-1,1]，基础步态只响应 X/Y/Yaw。

## 3. SDK 模式（我方 runner 通路）
- 协议 1.2.8 运动 SDK 模式下发：Type 0x00100005, Cmd 0x00300002, Items.SDKEnable true/false, Frequency 1~200（关节话题频率）。→ **切 SDK 不一定要手柄**；但协议口默认加密（DTLS 10.21.33.103:30004 / TLS :30003，关加密需技术支持），现场能否用待验。
- /JOINTS_DATA 200 Hz 只在 SDK 模式下有（与 Frequency 一致）。

## 4. 状态与留痕话题
| 话题 | 内容 | 频率 |
|---|---|---|
| `/MOTION_INFO`（drdds/MotionInfo） | vel_x/vel_y/vel_yaw/height、state、gait | 20 Hz |
| `/IMU`（sensor_msgs/Imu）、`/LIDAR/POINTS`（PointCloud2） | 本体传感器（机器人主机上） | 200 / 10 Hz |
| `/fault_aggregator`（FaultEventArray） | 活跃故障快照（关节超限 0x8014、IMU 超时 0x8201…） | ~1 Hz |
| 协议心跳 1.2.1（≥1 Hz）后 2 Hz 基础状态（MotionState/Gait/HES/Version STD·PRO）、10 Hz 运控状态（速度/姿态/16 关节角）、2 Hz 设备状态（电池/温度/CPU）、异常上报 | 上位机 | |

## 5. 内置导航任务（1.4，Version=PRO 才支持，错误 0xE00A）
单点导航任务：PointInfo（过渡/任务/站立/充电/**楼梯准备点 4**）、Gait 0x3002/0x3003、Speed 低/正常/高、NavMode 直线 0 / 自主 1（建议多段直线代替自主）、ObsMode、Terrain（实心/镂空/无踢面楼梯/累积帧）、Posture（正常/匍匐）。

## 6. 对我方文档的影响
- 档案"通路 1（官方运控）"接口按本表写：导航模式 + 0x3002/0x3003 + /NAV_CMD 10 Hz（或真实轴指令）。
- 楼梯段操作规程：进楼梯前停稳 → 切 0x3003 → 再走；到顶停稳 → 切 0x3002。
- 我方通路 2 的进入可写"手柄或协议 1.2.8 切 SDK 模式"（协议口加密现场待验）。

## 7. 组委会示例 `asdu_udp_control.py`（09-19 群发；副本 决赛文档/asdu_udp_control.py，md5 b6aed078）
- **前置操作（组委会原话）**：在 103 主机 `vi /var/opt/robot/conf/robot_server/Network.toml`，把 `enableTls = true` 改为 `false`；机器狗趴下后**整机重启**生效。**开启后遥控器将无法使用**，须在空旷场地测试。
- 通道：明文 UDP `10.21.33.103:30004`；示例在 103 上本机运行，外部客户端（AGX）同网段亦可连。
- 帧：16 字节头 `struct '<4sHHBBB5s'` = 同步 `eb 91 eb 90` | 长度(2) | 报文 ID(2) | 格式 0x01=JSON | 包序号 | 版本 0x01 | 5 字节 0；JSON 体里 Type/Command 是**整数**（如 0x00100064 → 1048676），不是 "0x…" 字符串（线上编码问题就此确定）。
- 心跳 1 Hz（Type 0x00100064 / Cmd 0x00000005）后，机器人向发心跳的 IP:端口回 2 Hz 基础状态 + 10 Hz 运控状态，可从中读 MotionState / Gait / Mode。
- 示例序列：趴下→**起立** MotionParam=1（协议站立后自动进 RL）→ **楼梯步态** GaitParam=0x1003（常规运动模式）→ 轴指令 1.2.5 `X=0.12`（比例值，≈0.2 m/s，即满量程约 1.67 m/s）连发 2 s、归零 5 帧 → **趴下** MotionParam=4。轴指令不回响应；2 s 内轴指令须来自同一客户端（0xE006）。
- 与指南的关系：示例走的是**常规模式 + 比例轴指令**；指南要求自主导航用**导航模式 + 0x3002/0x3003 + 真实轴指令(m/s)**或 `/NAV_CMD`。两条都可用，选哪条由导航层定并写进冻结记录。
- **安全影响**：遥控器失效期间，急停链 = 机身硬急停 HES + 协议软急停（MotionParam=2 关节阻尼）+ 上位机看门狗（心跳/指令超时）。**我方尚未在真机验证协议软急停的响应时间**，上路前必测。
- 我方现成件：`s10_dev/s10proto.py`（09-05，同一帧头、JSON/XML、probe/listen/send）可直接改成 `/cmd_vel → 轴指令` 适配器；`steer_pub.py` 的 `/STEER` DDS 通路保留为备选。
