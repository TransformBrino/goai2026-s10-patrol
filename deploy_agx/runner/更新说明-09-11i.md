## 为什么
真机 09-12 17:24 楼梯翻车：楼梯专家 StairN-C_9300 切入后 0.1～0.3 s 左前轮动作 −9→−14（其余 −2～−4），×5 = −65 rad/s 目标，石材上左前轮空转到 −57 rad/s，牵引不对称 → 右转 40°、侧倾 22° 翻。
仿真同样条件下四轮动作 −13.1 / −2.8 / −2.7 / −2.5，**9300 就是靠左前轮驱动**（StairN-C 全部检查点如此，是训练线通病；换检查点走不通）。
把楼梯槽的轮子缩放降到 3（左前轮目标 −65 → −32 rad/s）后，仿真里四轮动作变成 −10.5 / −3.6 / −2.9 / −3.6，偏航摆动减半，照样登顶。主策略、ClimbH 不动。

## 怎么用
起 runner 时加环境变量 `S10_AS_WHEEL_PIT=3`（控制台 night4g 起支持给 runner 传 S10_AS_WHEEL 类变量）。不设 = 0911h 行为。

## 回退
